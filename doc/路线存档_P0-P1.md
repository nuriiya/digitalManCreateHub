## 需求编写人 · 五原语分解（本体重分类，2026-08-27 定稿）

> 用户决策：**摒弃"三实体"万物皆对象的思维**，回到五原语体系对需求编写人重新分类。判断标准：先问每样东西的本质（名词/关系/动词/计算/界面），再问它叫什么。

| 原语 | 本质 | 需求编写人归属 |
|---|---|---|
| Object 对象 | 承载事实与证据、需落库的名词 | 需求条目 / 澄清请求 / 提名轨迹 / 需求文档 |
| Link 链接 | 对象间有向、带基数的关系 | 对话→条目 1:N · 条目→澄清 1:N · 条目→轨迹 1:N · 条目→文档 N:1 · 条目↔条目 去重 |
| Action 动作 | 状态迁移的动词 | 提名 / 裁决 / 修复（≤2 轮）/ 提出澄清 / 应答澄清 / 组装 |
| Function 函数 | 确定性护栏（无 LLM、无状态、可重放） | 结构关 G-04 · 语义关 G-03/05/06/08 · 证据关 G-01/02 · 编号生成 · 文档渲染 · 降级提名器 |
| Interface 界面 | 人与数字人的接触面 | 身份视图 · 调用步骤 · 本体限制 · 提名-裁决试验台 · 澄清对话 · 文档导出 |

旧三实体去处：需求对齐 → Actions + Link（"对齐"是过程不是东西）；需求文档 → 一个 Object + Function（渲染）；需求审核 → Functions（三关校验）+ Action（组装放行）（"审核"是能力不是东西）。数字人本身不是第六原语，是五元组的封装体：Interface=身份、Action=技能、Function=护栏、Object+Link=作业世界。对话原文（transcript）不算数字人对象——外部证据基准，归对话域所有。

**实现状态**：P0 代码落地形态仍为 14 Object 平铺（含系统支撑与配置实体）。五原语重分类是**目标语义模型**；是否以及何时按此重构 ontology.yaml，留待 P0 收尾/P1 启动时决策。

## 第六原语：Reflection（反思）

> 2026-08-27 用户决策：在五原语之上增加第六原语，承载 **AI 独自复盘、独自优化**。
> 命名：候选有"举一反三 / 复盘 / 反思 / 洞察 / 泛化"，取 **Reflection（反思）**——
> 与前五原语同为单词名词、风格一致；与 Agent 文献（Reflexion 类自我反思机制）一致；
> "复盘（Retrospective）"偏事件性；"洞察（Insight）"是产物不是能力，用作其产出对象名；
> "泛化（Generalization）"在 ML 语境语义已被占用；"举一反三"是效果描述不是能力命名。

- **能力定义**：任务完成后，对自身 Trace 复盘，产出"改进提名"（R1–R6 六类：规则缺口/规则误伤/澄清模板化/工具链/画像/用户修正模式）。
- **触发**：每次对话结束后异步执行。
- **输入**：nomination_trace（P0 已按对象留痕的三关校验记录，正好是反思层的原料）。
- **产物**：**洞察（Insight）对象** + 改进提名。

**三条铁律**（自我学习不得破坏安全性）：
1. 反思只提名，不裁决——洞察必须通过与需求条目相同的确定性三关校验 + 分级审批（低风险自动/高风险人工）。
2. 学习成果回流 Spec 重编译生效，**禁止运行时热更新**。
3. 守护规则（G-01~G-08）本身不在反思可修改范围内，变更必须人工审批。

**与前五原语的关系**：Reflection 内部仍由五原语组成——洞察=Object、复盘=Action、回归重放=Function、洞察看板=Interface、洞察→Spec=Link。它新增的是"自我指向"这一能力维度，而不是绕开原有约束体系。

## P1（下一阶段）：数字人工厂 + 反思层

**目标**：创建自动化 + 诞生后自我进化。依据《数字人工厂与反思层架构设计.html》。

1. **工厂层**：元本体约束 Spec（五基因段 YAML）→ 编译流水线（校验/合并/编译/冒烟/注册）→ 版本化灰度
2. **反思层五阶段**（即第六原语 **Reflection 反思** 的落地形态）：Trace 采集 → 双模型反思提名（Flash 高频 + GLM 跨 Trace 归纳，R1–R6 六类改进）→ 确定性回归重放裁决 → 分级固化（低风险自动/高风险人工）→ 回流 Spec 重编译
3. **冷启动策略**：前 ~50 条改进全人工审批，再放开低风险自动固化
4. **用户画像**：工作偏好（低风险）+ 背景推断（高风险带证据链，只影响呈现不入裁决），四环生命周期 + 可见/可纠正/可删除

**P1 验收标志**：用 Spec 一键编译出第二个数字人（需求审核人），验证"换基因不换机制"。
