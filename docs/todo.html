愿景 · 三层里程碑

每层都真实可用，下一层建在上一层之上。

M1 · 核心平台（专业数字人）

部门文档一键入库 → 本体分解 → 数字人装配 → 对话/考核/评测/版本回滚。能力通过的工具沉淀为可复用代码。

已实现 ≈ 90%

M2 · 双路径形态（+基础数字人）

Spec 编译路径落地：平台通用本体库 + 编译器 + 元本体校验，让平台方也能「写 Spec 造数字人」，与 RAG 知识包路径汇入同一审批测试闭环。

未开始 ≈ 5%

M3 · 反思自进化 + 规模化

Reflection 复盘-回流-重编译闭环；定时调度器驱动「持续调研 → 入库 → 本体更新」；多数字人协作编排成为日常工作流。

未开始 ≈ 3%
