# 讨论记录（discussions）

本目录保存**我们之间的讨论沉淀**——调研结论、方案选型、决策依据、踩坑记录。

与 `docs/` 下三份**契约文档**的区别：

| 文档 | 性质 | 是否约束实现 |
|---|---|---|
| `docs/design.md` / `requirement.md` / `test-metrics.md` | 系统设计 / 需求 / 测试指标 | ✅ 硬性约束，变更必须三份同步 |
| `docs/discussions/*`（本目录） | 讨论与调研过程 | ❌ 不直接约束；**结论一旦被采纳，必须回写进上面三份文档** |

命名约定：`YYYY-MM-DD-主题.md`，一篇一个主题，**只增不改**（后续讨论以新文件续写，避免历史被静默改写）。
