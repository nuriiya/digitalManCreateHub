# 数字人平台 · 使用手册

> 面向**使用者**的操作手册：平台能做什么、每个页面怎么用、常见场景怎么走。
> 开发者文档见 `README.md`（启动/部署）与 `docs/design.md`（设计）。

---

## 1. 这是个什么平台

用一句话说：**你描述需求，数字人替你干活，产物每一步可追溯。**

平台里有三种"角色"协作：

| 概念 | 是什么 | 例子 |
|---|---|---|
| **数字人** | 有身份、有知识（本体）、有动作、受规则约束的智能体 | 「DFMEA 工程师」「射频硬件专家」 |
| **pipeline** | 数字人的协作编排（流程图）：谁先做、谁复核、产物给谁 | 搜索部件 → 4 专家并行分析 → 汇总 → 复核 → 落库 |
| **本体库** | 平台共享的知识图谱（概念/规则/流程），是数字人的"教科书" | 「失效模式」「取值优先级链」 |

三条铁律贯穿所有功能（你不需要记，但要知道平台为什么这样设计）：

1. **绝对准确**——每个结论都要有来源（历史案例 / 准则表 / 专家确认）
2. **不知道就说不知道**——没有证据时明确标注"AI 生成待确认"，不编造
3. **你是唯一终审点**——AI 只提名，批准/否决永远由你操作

## 2. 登录与页面总览

- 地址：`http://localhost:8000`
- 默认账号：`admin` / `123456`（设置页可改密码）

| 页签 | 干什么用 |
|---|---|
| **对话** | 日常使用主入口：提问、多会话管理、生成 MCP、一句话创建 pipeline |
| **数字人** | 数字人工作台：查看/创建/编辑数字人，给数字人喂文档 |
| **RAG 预览** | 知识库内部视图：文档、分段、标签、检索命中 |
| **本体图谱** | 知识的图谱视图：审批本体候选、从图谱点选创建数字人 |
| **编排** | pipeline 画布：查看/拖动/编辑/运行/训练 pipeline |
| **测试** | 数字人 A/B 对比测试（消融实验） |
| **MCP 沙盒** | 外部工具服务（如论文搜索）的导入、审批、启停 |
| **设置** | LLM 配置、密码、资产导出/导入 |

## 3. 五分钟上手：创建你的第一个数字人

最快路径是**模板实例化**（平台内置 4 个模板，开箱即用）：

1. 进入 **数字人** 页 → 「模板」面板
2. 选一个模板（如「DFMEA 工程师」），填槽位（如应用领域 = "手机 WiFi 模块"）
3. 点**实例化** → 数字人立刻出现在列表里，本体、动作、锚点全套就位
4. 切到 **对话** 页，提问即可——系统自动路由给对口的数字人

> 其它创建方式见 §5 场景教程。模板路径最快，图谱种子路径最灵活，
> 向导路径最自由（纯空白开始）。

## 4. 页面功能详解

### 4.1 对话页（日常主入口）

- **自动路由**：输入问题，系统判断交给哪个数字人回答（气泡上标注"由『XX』回答"）
- **多会话**：左侧会话列表可新建/重命名/删除；按会话组织历史
- **多选删除**：会话头部「多选」→ 勾选消息 →「删除所选」；支持全选
- **生成 MCP**：输入需求描述 → 自动生成一个工具服务（待你在 MCP 沙盒页审批）
- **创建 pipeline**：输入需求描述（如"先调研再写报告再复核"）→ 自动生成
  流程图草稿（待你在编排页审批）
- 生成的 pipeline 卡片**就地**可校验/批准/运行，产出直接在对话页查看

### 4.2 数字人页（工作台）

- **列表—详情**：左侧数字人列表，右侧详情（使命 / 提示词 / 锚点 / 本体段 / 动作）
- **创建**：三步向导（名字/使命 → 描述/提示词 → 分类）
- **上传文档**（详情页按钮）：把文档喂给该数字人 —— 自动入库 RAG →
  范围化提取本体 → 生成"装配待确认清单" → 你一键终审并入
- **模板面板**：实例化内置模板；「存为模板」把现有数字人沉淀为可复用模板
- **任务抽屉**：任意页面可开，看后台任务（摄取/提取/装配）实时进度

### 4.3 本体图谱页

- **本体库**：全部知识条目（概念/规则/流程），带标签与热度分层
- **审批**：LLM 提名的候选本体在这里等你批准/拒绝/暂缓（三关校验过的才会到这）
- **图谱**：可视化浏览知识网络，点选节点看证据
- **从图谱创建数字人**：点选若干节点作为"种子" → 创建数字人 →
  AI 从本体库提取适配本体
- **二次编排**：GLM 对本体库做相关度分档 + 合并/删除提名，你一键终审

### 4.4 编排页（pipeline 画布）

- **流程图**：节点（数字人/确定性步骤）+ 关系（设计/供给/审核门/询问/交接）
- **画布操作**：
  - 拖动节点排布（位置自动保存，刷新不丢）
  - 滚轮缩放（40%~250%）、拖空白处平移
  - `Ctrl+Z` / `Ctrl+Shift+Z` 撤销/重做
- **编辑**：添加节点/关系、绑定数字人
- **运行**：批准后运行；运行进度、每步交接物、复核门结论实时可见
- **版本族**：历次迭代自动归档为历史版本（默认隐藏，勾选"显示归档版本"可查）
- **训练**：Pipeline 训练师对 pipeline 里的数字人做能力训练（见 4.7）

### 4.5 RAG 预览页

- 文档/分段/标签的内部视图；检索测试（命中哪些分段、分数多少）
- 分段内容类型（词表可自定义）与置信度/强制等级

### 4.6 MCP 沙盒页

- 导入 MCP 定义（JSON）→ 审批 → 启动容器 → 数字人即可调用
- 例：论文搜索（arXiv / Semantic Scholar）——需求分析师数字人可联网查文献

### 4.7 测试页 / 训练师

- **测试**：两个数字人对同一题的开卷对比（消融实验）
- **训练**（工作台/编排页内）：找训练集 → 建基线 → 失败归因 → 装配本体 →
  复测提升率，循环到达标

### 4.8 设置页

- **LLM 双通道**：generator（提名/高频）+ judge（归纳/核验），填 key 即用
- **Ollama**：本地模型管理（拉取/状态）
- **资产导出 / 导入**：一键打包全部数字人/本体/pipeline/MCP 为 JSON
  （不含 RAG 文档库）；导入幂等——同名只补不改，跨机器迁移安全

## 5. 场景教程

### 场景 A：从零建一个领域专家（模板路径，最快）

```
数字人页 → 模板面板 → 选「部件专家」→ 填槽位（专家名/领域/关键概念）
→ 实例化 → 完成（本体+动作+锚点全套就位）
```

### 场景 B：给数字人喂私有文档

```
数字人页 → 选中数字人 → 「上传文档」→ 选文件（pdf/txt/md）
→ 等摄取+本体提取完成 → 看「装配待确认清单」→ 一键终审并入
```

### 场景 C：一句话建 pipeline 并跑起来

```
对话页 → 点亮「创建 pipeline」→ 输入"为手机 WiFi 模块做 DFMEA，
先自主搜索部件清单再逐个分析"→ 生成草稿卡片 → 校验 → 批准 → 运行
→ 卡片里看运行进度与 DFMEA 产出
```

### 场景 D：考试迭代（让 pipeline 达标）

pipeline 跑完后用考卷判分（如 DFMEA 的 30 题×150 判定点，阈值 98%）。
未达标 → 归因（缺动作？缺本体规则？）→ 补齐 → 复跑，循环到达标冻结。
平台侧只补"零件"（动作/规则/兜底），**从不改产出内容**——保证考卷有效。

### 场景 E：换电脑 / 双机协作

```
旧机器：设置页 → 「导出资产包」→ 得 digitalman-bundle-<日期>.json
        （建议同时 git push 代码）
新机器：git pull → 启动 → 设置页 → 「导入资产包」→ 选该 JSON → 完成
```

导入幂等：已存在的同名资产自动跳过，不会重复也不会覆盖你的修改。

### 场景 F：让数字人联网查论文

```
MCP 沙盒页 → 导入/确认 paper-crawler 服务 → 审批 → 启动
对话页 → 问需求分析师数字人："帮我搜 visual grounding 最新论文"
→ 它调用 arXiv/Semantic Scholar 返回标题/作者/摘要/PDF 链接
```

## 6. 常见问题（FAQ）

**Q：数字人回答"我不知道"是坏了吗？**
不是——这是铁律②在工作。它的知识库里没有证据时不编造。喂文档（场景 B）
或装配本体可以扩大它的知识面。

**Q：创建的 pipeline 运行后某些步骤"空转"？**
通常是该步骤绑定的数字人没有所需动作。编排页编辑该节点，换成绑定了
对应动作的数字人（生成时会提示每个数字人有哪些动作）。

**Q：复核门（红色菱形）FAIL 了怎么办？**
平台会自动把驳回意见回灌给产出节点重做（最多 2 轮）。仍 FAIL 则中止，
等人工处理——这是设计行为，不是故障。

**Q：本体图谱页看不到某些数字人的知识？**
数字人的本体段会自动同步进本体库（带 `persona:数字人名` 来源标签）。
若仍找不到，检查该条目是否还在"待审批"状态。

**Q：LLM 报 402 / Insufficient Balance？**
DeepSeek 账户余额耗尽。设置页换 key，或充值后重试。平台不会用降级通道
冒充核验结论（宁可不打分）。

**Q：怎么备份整个平台？**
两步：① git 提交代码；② 设置页导出资产包。RAG 文档库可重新上传，
或直接备份 PG 数据卷。

## 7. 功能边界（当前版本）

- 联网搜索目前仅限论文检索（MCP paper-crawler：arXiv / Semantic Scholar /
  OpenAlex / DBLP / Google Scholar）；通用网页搜索未接入
- 搜索结果暂不自动入 RAG 库（元数据返回给对话，用完即弃）——
  入库链路在规划中（design §19 后续）
- pipeline 运行依赖 LLM 账户可用；本地 Ollama 可作降级通道（设置页切换）
- 复合审批（多级会签）未实现；当前每个审批点都是单人一键终审
